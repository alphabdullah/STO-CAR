# STO Car - Design System

## Color Palette (Automotive Marketplace)

| Token | Hex | Usage |
|-------|-----|-------|
| **bgPrimary** | `#0A0C0F` | Main background |
| **bgSecondary** | `#14171C` | Cards, surfaces |
| **bgCard** | `#171A21` | Elevated cards |
| **primary** | `#DC2626` | CTAs, accent (automotive red) |
| **secondary** | `#F59E0B` | Auctions, highlights (amber) |
| **success** | `#10B981` | Success states |
| **textPrimary** | `#F8FAFC` | Headings |
| **textSecondary** | `#94A3B8` | Body text |
| **textTertiary** | `#64748B` | Muted/captions |

## Responsive Breakpoints

- **XS** < 360px (small phones)
- **SM** < 600px (phones)
- **MD** 600-900px (tablets)
- **LG** 900px+ (desktop)

## Usage

- `AppTheme` - Global theme (colors, buttons, inputs)
- `AppDesign` - Design tokens for custom widgets
- `AppPrimaryButton` / `AppSecondaryButton` - Responsive buttons
- `AppCard` - Responsive cards
- `ResponsiveValues.hp(context)` - Adaptive padding

## Typography

- **Font**: Poppins (Google Fonts)
- Headings: 28/22/18px
- Body: 16/14px
- Captions: 12px
